# 猫猫番茄钟桌面应用设计文档

## 1. 产品定位

这是一个 Windows 优先的像素猫猫桌面番茄钟，不是任务管理器，也不是完整桌宠。它的目标是陪用户专注、到点提醒休息、并让用户愿意把它常驻在桌面角落。

### 一句话定义

一只会陪你专注、提醒你休息、完成后给你小鱼干的像素猫猫桌面挂件。

## 2. 设计原则

### 2.1 陪伴优先
所有设计都要服务于“有一只猫在桌面陪你”。

### 2.2 低打扰
提醒必须温柔，不能像打卡软件一样压迫用户。

### 2.3 轻量可常驻
它要适合一直开着，不应该占用太多注意力。

### 2.4 功能收敛
第一版只做稳定番茄流程、轻互动和统计，不引入复杂任务系统。

### 2.5 可恢复
用户关闭或重启后，应尽量恢复上次倒计时，减少中断感。

## 3. 产品范围

### 3.1 必做
- 专注 / 休息计时
- 开始 / 暂停 / 继续 / 重置
- 预设模式 + 自定义时长
- 像素猫猫展示
- 点击 / 摸摸猫的轻互动
- 完成番茄后小鱼干 +1
- 简短鼓励文案
- 应用内提醒卡片
- 默认轻提示音
- 今日完成番茄数
- 今日专注总时长
- 恢复当前倒计时
- 主窗口 + 迷你挂件模式

### 3.2 暂不做
- 任务列表
- 账号系统
- 云同步
- 社交功能
- 复杂养成数值
- 历史图表
- 多平台首发

## 4. 成功标准

第一版的成功标准有两个：

1. 用户能稳定完成专注、休息、提醒和恢复流程。
2. 用户愿意把它常驻在桌面角落，而不是只打开一次就关掉。

## 5. 核心状态

### 5.1 未开始
- 猫猫在桌面上待命
- 显示默认时长或预设模式
- 主按钮为“开始专注”

### 5.2 专注中
- 倒计时运行
- 猫猫进入安静陪伴状态
- 可轻微动画，不要太活跃
- 主按钮为“暂停”

### 5.3 暂停中
- 倒计时冻结
- 猫猫表现为疑惑或等待状态
- 主按钮为“继续”

### 5.4 专注完成
- 弹出应用内提示卡片
- 小鱼干 +1
- 显示鼓励文案
- 等用户点击“开始休息”

### 5.5 休息中
- 倒计时运行
- 猫猫变成放松、打盹、伸懒腰状态
- 主按钮为“暂停休息”

### 5.6 休息完成
- 弹出温柔提示
- 用户点击“开始下一轮”
- 不自动强制进入下一轮专注

## 6. 用户主流程

```text
打开应用
→ 看到桌面猫猫挂件
→ 选择预设或自定义时长
→ 点击开始专注
→ 专注倒计时
→ 到点弹出完成卡片
→ 小鱼干 +1
→ 点击开始休息
→ 休息倒计时
→ 到点提醒休息结束
→ 点击开始下一轮
```

### 关键原则
- 专注结束后先给反馈，再进入休息
- 休息结束后由用户决定是否继续
- 所有提醒尽量留在应用内完成

## 7. 窗口与界面结构

### 7.1 完整主窗口
完整主窗口用于开始、调整和查看状态。建议布局如下：

```text
┌────────────────────────────┐
│ TomatoBuddy          设置   │
│                            │
│        [像素猫猫]           │
│     猫猫轻微动作区域        │
│                            │
│        专注陪伴中           │
│          24:18             │
│                            │
│ 今日小鱼干：3 条            │
│ 今日专注：1 小时 15 分钟    │
│                            │
│    [暂停]      [重置]       │
│                            │
│       [切换迷你挂件]        │
└────────────────────────────┘
```

### 7.2 迷你挂件模式
迷你挂件是长期常驻状态，建议布局如下：

```text
┌──────────────┐
│   [猫猫]      │
│   24:18      │
│  专注中       │
└──────────────┘
```

或横向版本：

```text
┌────────────────┐
│ [猫猫] 24:18   │
└────────────────┘
```

#### 迷你挂件行为
- 可拖动
- 可置顶，默认开启
- 点击挂件可展开完整窗口
- 右键或菜单可暂停 / 继续 / 重置
- 专注完成时在挂件旁弹出提醒卡片

### 7.3 应用内提醒卡片
提醒卡片用于替代强系统弹窗。

专注完成：

```text
┌────────────────────────┐
│ 太棒了！               │
│ 猫猫奖励你一条小鱼干。 │
│                        │
│ [开始休息]   [稍后]    │
└────────────────────────┘
```

休息完成：

```text
┌────────────────────────┐
│ 猫猫伸了个懒腰。       │
│ 要开始下一轮了吗？     │
│                        │
│ [开始下一轮] [稍后]    │
└────────────────────────┘
```

### 7.4 设置页面
设置页第一版保持很少选项：

```text
专注模式
- 短专注：15 / 3
- 标准番茄：25 / 5
- 深度专注：50 / 10
- 自定义：__ / __

声音提醒：开启
窗口置顶：开启
启动时恢复上次计时：开启
默认打开迷你挂件：关闭

[保存]
```

### 7.5 猫猫互动反馈
用户点击或摸摸猫时，可反馈一句短文案，例如：
- 喵，我在陪你。
- 再坚持一下下。
- 别忘了喝水。
- 我会安静一点。

互动规则：
- 点击猫不会影响计时
- 不弹大窗口
- 只显示一条短气泡
- 专注中反馈更克制
- 休息中反馈更活泼

## 8. 数据需求

### 8.1 用户设置

```json
{
  "focusMinutes": 25,
  "breakMinutes": 5,
  "preset": "standard",
  "soundEnabled": true,
  "alwaysOnTop": true,
  "restoreSession": true,
  "defaultMiniMode": false
}
```

字段说明：
- `focusMinutes`：专注时长
- `breakMinutes`：休息时长
- `preset`：当前使用的模式
- `soundEnabled`：是否开启轻提示音
- `alwaysOnTop`：挂件是否置顶
- `restoreSession`：是否恢复上次计时
- `defaultMiniMode`：是否默认打开迷你模式

### 8.2 当前会话状态

```json
{
  "mode": "focus",
  "timerState": "running",
  "startedAt": "2026-05-11T10:00:00+08:00",
  "durationSeconds": 1500,
  "remainingSecondsSnapshot": 1200
}
```

规则：
- 若应用关闭时计时正在运行，重启后根据真实时间差计算剩余时间
- 若时间已超过结束点，重启后进入对应完成状态
- 若用户手动暂停，则恢复暂停时的剩余时间
- 不依赖简单 interval 保存倒计时，避免计时漂移

### 8.3 今日统计

```json
{
  "date": "2026-05-11",
  "completedPomodoros": 3,
  "focusSeconds": 4500,
  "fishCount": 3
}
```

规则：
- 完成完整专注后，`completedPomodoros +1`
- 小鱼干数与今日完成番茄数一致
- 今日专注总时长只统计完成的专注周期
- 跨天后今日统计重置
- 历史统计第一版不做

### 8.4 界面状态

```json
{
  "windowMode": "mini",
  "windowPosition": {
    "x": 1400,
    "y": 780
  }
}
```

规则：
- 保存主窗口 / 迷你挂件模式
- 保存窗口位置
- 下次启动尽量恢复到上次位置
- 如果位置超出屏幕范围，需要回到默认位置

## 9. 业务规则

### 9.1 完成番茄规则
只有以下情况计入完成：
- 用户启动专注
- 完成完整专注倒计时
- 到达专注完成状态

以下不计入：
- 中途重置
- 关闭后恢复时尚未到达专注结束点
- 手动跳过
- 只完成休息

### 9.2 休息规则
- 专注完成后不自动开始休息
- 用户点击“开始休息”后进入休息倒计时
- 休息结束后不自动开始下一轮
- 用户点击“开始下一轮”才开始下一次专注

### 9.3 自定义时间规则
建议限制：
- 专注时长：1–180 分钟
- 休息时长：1–60 分钟

原因：
- 防止 0 分钟导致状态异常
- 保留深度工作场景
- 不把第一版做得过度复杂

### 9.4 提醒规则
- 专注完成：应用内卡片 + 轻提示音
- 休息完成：应用内卡片 + 轻提示音
- 如果应用在迷你模式，卡片出现在挂件附近
- 如果主窗口不可见，第一版到点时显示迷你挂件或恢复主窗口，并在窗口附近展示提醒卡片
- 系统通知暂不作为主要提醒，但后续可加入

### 9.5 互动规则
- 点击猫只触发气泡文案或轻动画
- 不影响计时状态
- 互动频率需要节制，避免干扰
- 同一句文案不要连续重复
- 专注中互动文案更短、更安静
- 休息中互动文案可以更活泼

## 10. 视觉风格

### 10.1 总体方向
第一版采用像素桌宠风 + 温柔桌面挂件感。

关键词：
- 像素
- 小巧
- 轻活泼
- 桌面常驻
- 温柔提醒
- 有陪伴感

### 10.2 颜色建议
- 主背景：浅米色 / 奶油白 / 低饱和暖灰
- 主体强调：像素黄、焦糖棕、柔和橙
- 专注状态：偏暖
- 休息状态：偏冷一点的浅蓝 / 薄荷绿
- 提示文案：深棕或灰黑，不要纯黑太硬

### 10.3 字体建议
- 标题和倒计时：圆润、可爱、可读性高
- 正文：清晰、简洁
- 不要用太商业化的默认系统感字体
- 不要让文字比猫猫更抢戏

### 10.4 动效原则
第一版动效要克制：
- 猫猫轻微跳动
- 眨眼
- 尾巴摆动
- 完成番茄时轻微庆祝
- 切换模式时有柔和过渡

不要做：
- 大幅弹跳
- 夸张粒子特效
- 太频繁的闪烁
- 打断工作的强动画

## 11. 非功能要求

### 11.1 稳定性
- 计时要准确
- 重启可恢复
- 长时间运行不应卡死

### 11.2 轻量性
- 应用应该小而轻
- 不要占太多 CPU
- 迷你挂件模式要尽量省空间

### 11.3 易用性
- 打开就能开始
- 不需要学习复杂规则
- 默认配置可直接使用

### 11.4 桌面适配
- 适配 Windows 优先
- 支持常见分辨率
- 挂件模式不要超出屏幕边缘

## 12. MVP 边界

### 12.1 第一版必须完成
- Windows 桌面应用
- 像素猫猫主窗口
- 迷你挂件模式
- 专注 / 休息计时
- 预设 + 自定义时长
- 开始 / 暂停 / 继续 / 重置
- 专注完成后应用内提醒卡片
- 小鱼干 +1 + 鼓励文案
- 轻提示音
- 今日完成番茄数
- 今日专注总时长
- 重启恢复计时
- 猫猫轻互动

### 12.2 第一版不做
- 云同步
- 登录
- 任务系统
- 历史图表
- 成就系统
- 复杂养成
- 多猫管理
- 跨平台首发

## 13. 最终产品一句话

一只像素猫猫在 Windows 桌面上陪你专注，温柔提醒你休息，完成后奖励你小鱼干。
